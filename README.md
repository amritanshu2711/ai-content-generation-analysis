# AI-Powered Content Generation & Analysis Platform

An AI-powered web application built with Python and Flask that helps users generate content and analyze text efficiently.

## Features

- AI-powered content generation
- Text sentiment analysis
- Text statistics and analysis
- Simple and user-friendly web interface

## Technologies Used

- Python
- Flask
- Groq API
- HTML
- CSS
- JavaScript

## Project Structure

- `app.py` — Main Flask application
- `templates/` — HTML templates
- `static/` — CSS and static assets
- `requirements.txt` — Python dependencies

## Installation and Setup

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies:

   `pip install -r requirements.txt`

4. Create a `.env` file and configure your Groq API key using the environment variable expected by your application.
5. Run the application:

   `python app.py`

6. Open the local URL displayed in your terminal.

## Security

Never commit API keys, passwords, or other secrets to GitHub.
